CodePen Theme Original
======================

The classic Twilight palette keeps bindings blue, members purple, strings
green, and comments muted.  Inline code such as ``editor.fontSize`` and
references to `Visual Studio Code`_ exercise interpreted text.

.. _Visual Studio Code: https://code.visualstudio.com/

Palette
-------

.. list-table:: Token roles
   :header-rows: 1

   * - Role
     - Color
   * - Keyword
     - ``#ddca7e``
   * - String
     - ``#96b38a``
   * - Comment
     - ``#717790``

.. note::
   The **Original** variant is upright.  The *Ligatures* variant keeps italics.

.. code-block:: typescript

   const theme = { name: 'CodePen Theme Original' };
   console.log(theme.name);
